# Project Objective
Build a clean, responsive, premium landing page and service workflow system for **Prashoes**, a shoe cleaning service business.

The app must support:

1. A premium homepage with interactive sections.
2. Order tracking by Order ID.
3. Service pricelist.
4. Member and promo information.
5. Pickup request form.
6. Before-after result gallery.
7. Google Maps contact link.
8. Supabase-ready architecture for orders, pickup requests, services, promos, gallery, and members.
9. Future admin dashboard support.

Purpose: store customer shoe cleaning orders and tracking statuses.

Potential columns:

- `id` UUID primary key
- `order_code` text unique not null
- `customer_name` text
- `whatsapp_number` text
- `service_id` UUID nullable
- `status` text
- `status_note` text
- `pickup_address` text
- `total_price` numeric
- `created_at` timestamp
- `updated_at` timestamp

Example statuses in Bahasa Indonesia:

- `Pesanan dibuat`
- `Sepatu diterima`
- `Sedang diperiksa`
- `Proses pembersihan`
- `Proses pengeringan`
- `Quality check`
- `Siap diambil`
- `Siap diantar`
- `Selesai`
